## Pipo Ventures

A UK software company.

and an EPUB, for self-publishing authors and publishers alike. Open by invitation at the moment.

**[Surfaceplate](https://github.com/pipoventures/surfaceplate)** — a free, open-source tool for
developers. It installs a working framework for how software gets built, reviewed and checked.
